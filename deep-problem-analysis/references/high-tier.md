# 高档编排

高档比中档多做两件事：**检索分路并行**（扩大召回、专门找反面），**视角互相隔离**（防止各个"专家"被主线程的倾向带着走）。分几路、起几个 subagent、要不要补一轮，都按问题需要决定；判断够不够看 SKILL.md 里高档的完成标准。没有 subagent 能力的环境，按同样的思路在主线程依次执行，并在报告里注明"视角未隔离"。

起 subagent 时显式指定 `model`，且不高于当前会话的模型。检索类可以用较小的模型；会诊和红队用与主线程同级的模型。

## 流程

1. 主线程完成第一段和关键问题门（要问的问题先问完）。
2. **并行检索**：按方向分路，同一轮发出。常用的方向有：
   - 成功路径：相同或相似问题被解决的项目、产品、方法
   - 失败与复盘：postmortem、弃用公告、踩坑记录、"why we stopped"
   - 争议与反对：对主流做法的批评、反方数据
   - 一手数据：官方文档、标准、论文、公开数据
   问题窄时可以合并几路；某一路收获明显多时可以再细分。失败与复盘这一路不要省。
   每个 subagent 收到：重新定义后的问题、真正目标、约束、本路的检索方向。要求返回案例表（做法 / 结果 / 原因 / 条件差异 / 来源链接 / 来源等级），找不到就明说，不要补编。
3. 主线程合并去重。各路结果还不怎么重合、或某一路明显找浅了，就针对性补一轮。然后写第二、三段，并整理一份**事实底稿**：事实、假设、案例表、跨领域类比。底稿里不写主线程自己倾向的方案。
4. **隔离会诊**：每个视角一个 subagent，同一轮发出，只拿事实底稿，回答 4.1 的四问。它们彼此看不到对方的答案。
5. 主线程拿各份独立判断做 4.2 交叉质疑，形成初步结论。
6. **红队**：把初步结论和事实底稿交给它，任务是给出最强的反驳和最可能的失败场景，而不是评价好坏。主线程逐条回应，回应不了的写进"最大风险"或修正结论。
7. 写完整报告（含证据台账、红队附录）并落盘，对话里给摘要。

## 给 subagent 的简报要点

- 说明它是哪一路或哪个视角，以及它的输出会被怎样使用。
- 给事实底稿，不给主线程的倾向；不要问"X 方案是否可行"这类引导性问题，问"这个问题你会怎样定义、推荐什么"。
- 要求每条判断带【事实】/【案例】/【推测】标签和来源。
