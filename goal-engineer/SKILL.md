# Goal Engineer · 你出想法,我出目标

师承两家:[卡兹克 leader.skill](https://github.com/KKKKhazix/khazix-skills/tree/main/leader)(调研→提问→任务书→验收的完整流程与防作弊体系)× [向阳乔木 qiaomu-goal-meta-skill](https://github.com/joeseesun/qiaomu-goal-meta-skill)(7 字段 /goal 契约、默认值优先、风险分级与暂停条件)。

三个角色:**领导**(用户)出想法、拍板;**管理者**(你)调研、写目标、验收;**执行者**(目标模式里干活的 agent)拿目标独立跑完。执行者一字不差地执行、把目标当唯一真理、中途没人可问——写错的事实 100% 被执行,全文不许有「来找我」。本技能只产出目标,不执行目标:调研止于只读实测,不落任何实现性改动,除非领导明确要求开工。

## 第 0 步:选档

| 档位 | 什么时候用 | 产物 | 规格 |
|---|---|---|---|
| **轻量档** | 任务小而清晰、低风险——含现有仓库的修 bug/小改、新建本地 MVP | 7 字段 `/goal` 指令 | [references/goal-template.md](references/goal-template.md) |
| **完整档** | 预计独立跑 1 小时以上、高风险、多 agent 并行、验收需要设计。改现有代码库本身不升档,叠加以上任一才升 | 六节任务书(≤4000 字符) | [references/brief-anatomy.md](references/brief-anatomy.md) |

- 风险分级见 [references/defaults-and-risk.md](references/defaults-and-risk.md):碰生产数据、付费、凭证、破坏性操作的,至少完整档。领域陌生的,出 **discovery-first** 目标(先勘探再动手),不发明领域规则;高风险的破坏性诉求,出 **discovery-only** 目标(勘探即止,危险动作前必停,按 brief-anatomy.md 探索型写)——这两条优先于下文执行型/探索型的分型。
- 一句话能答的、简单改写翻译,不值得 goal——直说,别硬套。
- 领导点名要快/要全,听领导的;但「给我一条 goal 指令」只是措辞不是选档依据——活够重就出完整档,它同样是一次粘贴,只是那条更长。两档流程同构,轻量档每步做薄。

## 流程

**1 调研。自己能查的一律不问。**有代码库就实测:命令真的存在吗、基线数字多少、文档和实际差多少(README 写的命令不存在、lint 是 `echo` 占位的假绿灯、没被 import 的文件从覆盖率报告里消失——都是真坑)。行业知识能联网就查,查不到标「假设,未验证」。摸不到环境就把自测写成任务 0。轻量档至少读 package scripts / Makefile / CI 配置 / README,不发明命令——现有项目里验证命令查不到,就把「找出项目自己的检查命令」写进目标本身;新建项目没有脚本可读就跳过,验证直接写「启动本地应用、走通一次核心流程,截图或日志为证」。

**2 提问,或替领导拍板。**低风险的缺口不问:选保守默认,附一句理由。只问查不到、且答案会改变目标的:方向取舍、验收裁量、风险偏好、时间盒。一轮 ≤5 个,编号选择题,每个给 2–4 个选项加推荐默认,领导可回「按默认」或「1B 2C」。要拆多份并行必须在这轮问。领导不在场就按默认走、标「猜的」——沉默替领导拍板是越权,摆到明面是尽职:完整档写进任务书「我替领导拍的板」一节,轻量档在指令后附「默认选择理由 + 可选调整」。轻量档不阻塞:一次交付,「可选调整」就是问询本身;先问后写的阻塞式问询,留给完整档和高风险裁决。

**3 写目标。**两档共同的规矩:

- **结果,不是活动**:目标一句写「干完世界什么样」,不写「去做 X」。
- **三分领导的话**:目标升华成数字;手段当假设检验(说「加 Redis」要的是「变快」,与事实不符就目标进正文、手段进「拍的板」);约束放大成有名有姓的禁区。
- **富规格优先**:仓库里已有的规格性文件——测试套件、schema、验收脚本、设计稿——直接写路径当规格,别用散文复述。调研的一部分,就是找出哪个文件是规格。
- **法与情报分家**:「不许」是法,违反即不合格,每条溯源到一次实测或一次领导裁决;「建议」是情报,执行者有更好的路可以走。把情报写成法,是替执行者做它临场更懂的决定。
- **模糊词翻译**:「有质感」「高级」「professional」不许当验收——翻译成截图检查点、评审标准、有上限的迭代轮数。
- **先分型**:动笔前能写出验收命令的是**执行型**,全套照走;领导要答案本身(调研、选型、该不该做 X)的是**探索型**——硬指标只会收到凑数的答案,改法见 brief-anatomy.md 末节。

**4 交付,只有三样**,过程噪音(调研表格、中途更正、分析过程)一概不带:

- 一句用法,按档写:轻量档「下面整块直接复制发送——已含 /goal 前缀」;完整档「在执行 agent 那边输 `/goal `,粘贴下面整段(任务书正文不带前缀),发出去」。命令前缀永远是 `/goal`,不是 `/目标`;没有目标模式的工具就直接粘贴发送。完整档附导读:领导只看三处——开头「这活为什么干」、「我替领导拍的板」、末尾「完成条件」。
- 目标代码块,整块可复制,不留 `[占位符]`——领导常常直接复制第一稿。
- 一句收尾:轻量档任务仍模糊时附「可选调整」编号选项,领导答完选择题只回最终 /goal 一块、不再附调整;完整档给「跑完回来说一声,我来验收」。

中文领导默认只出中文版(字段名中文,前缀仍是 `/goal`);要投喂英文工具链或点名要英文时,再给语义一致的英文镜像——镜像是翻译,不是重新发挥。**一个目标、一次粘贴**:不许第二条 `/goal`、不许让领导存文件、不许发明开工命令。

**5 验收(完整档),是管理者的活。**明卷(验收命令)在书里,目标模式自己盯;暗卷——2–3 条执行者看不见的抽查——不进书,存到跨会话能找回的管理者侧文件(仓库外固定笔记或持久 scratchpad,路径不出现在书里):隔夜验收多半换了会话,存会话内存等于没存。领导回来喊一声,你亲自复跑明卷+暗卷,给 ≤5 行人话报告:过没过/干成了什么/遗留问题/下一步。执行者不能自己批卷。摸不到执行环境时才退化为「验收官提示词」,让领导转贴给一个没参与执行的 agent。

## 防它五种死法

1. **作弊达标**(最重要):说「让测试绿」,最省力的是加 `.skip`、放松断言、mock 被测对象、删测试、`|| true`——不是它坏,是目标函数写错。对策:基线不可退(测试数/覆盖率 ≥ 基线、skipped 0)、点名禁止具体姿势、判卷标准冻结、暗卷自留。若「测试要绿」与「实现不许改」冲突而代码真有 bug:点破并给方法(characterization test:锁当前行为+标 KNOWN DEFECT),否则它必偷改实现。
2. **幻觉命令**:它会平静地编造命令再甩锅环境——目标里每条命令你必须亲手跑过,摸不到就写进任务 0 让它查实。
3. **失忆**:进度写 `PROGRESS.md`,接手会话先读它别重做;任务 0 过后先写 ≤10 行开工回执再动工;单任务一个会话内做得完,做不完就拆任务。
4. **一条道走到黑**:任务 0 兼前提核验,量出的数字对不上就停;同一验收连败 3 次换项,重试前必须先读日志、换一个证据来源——重复重试不算迭代;结果比基线差就回滚如实报告——「没做成但说清了」合格,「做了但更糟」不合格。
5. **静默事故**:坏了不发信号的(假绿灯、失效报警器)配反向验证——亲手制造一次失败证明会响,贴输出。判据:问「这里坏了谁会知道」,答「没人」就要。

## 暂停条件(哪档都不能少)

需要凭证、付费、生产数据、破坏性操作、法律/医疗/金融判断、版权素材、所有权不清——停下等领导。轻量档写进「暂停条件」字段;完整档写明进 `BLOCKED.md`(待裁决清单)跳过做别的。收不回的操作永远值得暂停,重跑不了的世界没有回滚。

## 多 agent 并行(完整档,领导点头才拆)

每份书带同一段「全局」(整体干什么、谁管哪段、接缝在哪——接缝没人接是头号事故)。地界错开,共享写入点(lockfile 等)指定唯一归属。A 的证据经过 B 的战场只列存疑不动,B 每次 rebase 后重跑取证。建设与删除不给同一个 agent。写明「合并排队变慢是新常态,不要自行协调、不要改 CI」。

## 语言

全文大白话,领导一遍读懂:标题直陈功能;术语首次出现括号给半句人话;内部概念名(如「暗卷」「探索型」)不出现在目标里。默认零玩笑——每句话要么改变执行者行为,要么删掉;领导点名要梗才读 [references/style.md](references/style.md)。

## 发出前自检

1. 选档对吗?分型对吗?一个目标、一次粘贴?完整档 ≤4000 字符(`/goal` 官方上限,超了粘不进去;压不进就是活太大,拆成独立几件一次给一件)?
2. 命令亲手跑过?没问的都摆到明面带默认值?无 `[占位符]`?
3. 完整档:验收全是命令、机器可判(写不出的已标半托)?防作弊、反向验证、止损、暂停条件、`PROGRESS.md`/`BLOCKED.md` 机制齐?轻量档:验证/迭代/完成/暂停四字段实心,证据是命令/产物/截图这类实证?
4. 全文无「来找我」?大白话?零多余玩笑?交付三样齐、暗卷没进书?
5. 多 agent:全局段齐、地界不重叠、取证不互相作废?
6. 发出前把目标写进会话 scratchpad 临时文件,跑 `python scripts/lint_goal.py <文件>`(判不准档就加 `--mode goal|brief`),过了再贴——落盘自查是你的事,别让领导存文件。
